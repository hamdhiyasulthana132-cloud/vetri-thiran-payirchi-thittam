# LegalEase

LegalEase is an AI-powered legal information assistant.

## Features

- AI legal information assistant
- Gemini integration
- FastAPI backend
- Streamlit frontend
- English/Tamil/Hindi response selection
- TXT export
- DOCX export
- PDF export
- API documentation
- Basic automated tests
